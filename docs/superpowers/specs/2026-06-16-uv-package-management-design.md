# Design: uv Package Management Migration

**Date:** 2026-06-16  
**Status:** Approved  
**Scope:** Replace flat `requirements.txt` with `pyproject.toml` + `uv.lock`; adopt uv as the sole environment and package manager.

---

## Problem

The project uses a flat `requirements.txt` that:
- Mixes production and dev/test dependencies
- Provides no lock file (reproducible installs depend on exact pinning by hand)
- Requires manual venv creation and activation
- Does not leverage uv's speed or project-aware tooling

## Goals

1. Single `pyproject.toml` as the source of truth for project metadata and dependencies.
2. Production deps in `[project.dependencies]`; dev/test deps in `[dependency-groups] dev`.
3. `uv.lock` committed to git for reproducible installs.
4. `.python-version` pins Python 3.12.
5. Developer workflow simplified to `uv sync` + `uv run <cmd>`.
6. `requirements.txt` removed; no derived artifact.
7. `start.bat` and `CLAUDE.md` updated to reflect uv commands.

## Non-Goals

- Not changing any application code, models, or tests.
- Not introducing linting or formatting tooling (flake8 already exists but is not managed by this project).
- Not adding a Dockerfile or CI pipeline (out of scope).

## File Changes

### 1. `pyproject.toml` (new)

```toml
[project]
name = "golden"
version = "0.1.0"
description = "Personal Finance App — single-user local budget manager"
requires-python = ">=3.12"
dependencies = [
    "fastapi==0.115.0",
    "uvicorn[standard]==0.30.6",
    "sqlalchemy==2.0.36",
    "alembic==1.13.3",
    "pydantic==2.9.2",
    "jinja2==3.1.4",
    "python-multipart==0.0.12",
    "aiofiles==24.1.0",
]

[dependency-groups]
dev = [
    "pytest==8.3.3",
    "pytest-asyncio==0.24.0",
    "httpx==0.27.2",
]

[tool.pytest.ini_options]
asyncio_mode = "auto"
```

### 2. `.python-version` (new)

```
3.12
```

### 3. `uv.lock` (generated — committed)

Generated by `uv lock` after `pyproject.toml` is in place. Not hand-edited.

### 4. `start.bat` (updated)

```bat
@echo off
uv run python finapp/run.py
pause
```

### 5. `requirements.txt` (deleted)

### 6. `CLAUDE.md` — Common Commands section (updated)

Replace:
```bash
pip install -r requirements.txt
```

With:
```bash
# Install all deps (creates .venv automatically)
uv sync

# Run the app
uv run python run.py

# Run tests
uv run pytest

# Add a production dependency
uv add <package>

# Add a dev/test dependency
uv add --dev <package>

# Regenerate lock file after manual pyproject.toml edits
uv lock
```

### 7. `.gitignore` (updated if needed)

Ensure `.venv/` is listed. Add `uv.lock` explicitly to tracked files (i.e., do NOT gitignore it).

## Developer Workflow After Migration

```bash
# First-time setup (or after git clone)
uv sync

# Start the app
uv run python finapp/run.py
# or
start.bat

# Run tests
uv run pytest

# Add new production dep
uv add requests

# Add new dev dep
uv add --dev pytest-cov

# Update a dep version (edit pyproject.toml, then)
uv lock
uv sync
```

## Invariants Preserved

- No application code changes; only packaging layer changes.
- All existing test commands continue to work via `uv run pytest`.
- `alembic` remains in production deps (used by `run.py` at startup).
- Loopback-only constraint (`127.0.0.1:5000`) unchanged.
