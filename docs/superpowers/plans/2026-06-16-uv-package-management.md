# uv Package Management Migration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `requirements.txt` with `pyproject.toml` + `uv.lock` so the project uses uv as its sole environment and package manager.

**Architecture:** All project metadata and dependencies live in `pyproject.toml` (PEP 621). Production deps go in `[project.dependencies]`; test/dev deps in `[dependency-groups] dev`. `uv.lock` is committed to git for reproducible installs. No derived `requirements.txt` is kept.

**Tech Stack:** uv 0.11+, Python 3.12, pyproject.toml (PEP 621), pytest-asyncio

## Task 1: Create `pyproject.toml`

**Files:**
- Create: `pyproject.toml`

- [ ] **Step 1: Create the file**

  Create `pyproject.toml` in the project root (`d:\golden\`) with this exact content:

  ```toml
  [project]
  name = "golden"
  version = "0.1.0"
  description = "Personal Finance App — single-user local budget manager"
  requires-python = ">=3.12"
  dependencies = [
      "fastapi==0.115.0",
      "uvicorn[standard]==0.30.6",
      "sqlalchemy==2.0.36",
      "alembic==1.13.3",
      "pydantic==2.9.2",
      "jinja2==3.1.4",
      "python-multipart==0.0.12",
      "aiofiles==24.1.0",
  ]

  [dependency-groups]
  dev = [
      "pytest==8.3.3",
      "pytest-asyncio==0.24.0",
      "httpx==0.27.2",
  ]

  [tool.pytest.ini_options]
  asyncio_mode = "auto"
  ```

  No `[build-system]` block — this is a local app, not a PyPI package.

- [ ] **Step 2: Verify uv can parse it**

  ```powershell
  uv tree
  ```

  Expected: dependency tree printed without errors.

## Task 7: Update `CLAUDE.md` — Common Commands section

**Files:**
- Modify: `CLAUDE.md`

- [ ] **Step 1: Replace the commands block**

  Find the `## Common Commands` section and replace the pip/pytest invocations so they read:

  ```bash
  # Install all deps (creates .venv automatically)
  uv sync

  # Run the app (alembic migrate + start server + open browser)
  uv run python finapp/run.py

  # Or on Windows
  start.bat

  # Run tests (unit + integration)
  uv run pytest

  # Run a single test
  uv run pytest tests/test_money.py -v

  # Lint
  uv run flake8 finapp/ --max-line-length=100

  # Add a production dependency
  uv add <package>

  # Add a dev/test dependency
  uv add --dev <package>

  # Alembic: create migration
  uv run alembic revision --autogenerate -m "description"

  # Alembic: apply migrations
  uv run alembic upgrade head

  # Alembic: rollback
  uv run alembic downgrade -1
  ```
