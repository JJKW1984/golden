================================================================================
RESPONSIVE DESIGN SPECIFICATIONS
================================================================================

Breakpoint: 768px (Tailwind "md" prefix)

Mobile-first approach:
- Base styles assume mobile (below 768px)
- Add/override with md: prefix for desktop behavior

Key responsive utilities:
- hidden md:flex - Sidebar (hidden mobile, flex desktop)
- block md:hidden - Bottom nav (visible mobile, hidden desktop)
- md:pb-8 - Main content padding adjustments
- md:bottom-8 - Floating button repositioning
- md:max-w-md - Modal width on desktop
- md:rounded-xl - Modal corner radius on desktop
